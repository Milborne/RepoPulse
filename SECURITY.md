# Security Policy

## Supported Versions

RepoPulse supports the latest published major version, currently `v1`.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub Private Vulnerability Reporting for this repository when it is enabled. If it is not enabled, contact the maintainer through a private GitHub security advisory workflow or request that private vulnerability reporting be enabled before sharing sensitive details.

Include:

- a clear description of the issue;
- steps to reproduce the behavior;
- the expected impact;
- affected versions or tags;
- any suggested mitigation.

Maintainers should acknowledge reports within 7 days and share a remediation plan when the issue is confirmed.

## Scope

RepoPulse runs local repository checks and does not intentionally call external services. Security reports should focus on action execution, unsafe filesystem behavior, dependency risks, or incorrect handling of untrusted repository content.
